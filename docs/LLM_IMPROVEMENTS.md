# EVA — Заимствования из классических LLM

> Какие архитектурные решения GPT/LLaMA/PaLM применимы к EVA и почему.

---

## Что берём

### 1. RoPE — Rotary Position Embeddings

**Что**: позиция кодируется поворотом вектора в 2D-подпространствах.
**Формула**: `f(x, pos) = x * cos(pos * θ) + rotate(x) * sin(pos * θ)`

**Почему для EVA**:
- RoPE естественно ложится на координатную парадигму — позиция = **угол в ℝ²⁴**
- Относительные позиции сохраняются: `q_i · k_j` зависит только от `(i-j)`
- Заменяет `pos_embed` (6K параметров) на zero-parameter решение
- Совместимо с FractalAttention — поворот на каждом уровне свой

**Выигрыш**: -6K параметров, +качество позиционного кодирования.

### 2. RMSNorm вместо LayerNorm

**Что**: нормализация только по variance, без mean-centering.
**Формула**: `RMSNorm(x) = x / sqrt(mean(x²) + ε) * γ`

**Почему**:
- Быстрее LayerNorm (нет вычитания среднего)
- Лучше работает в глубоких сетях (LLaMA использует)
- Меньше параметров (нет β — bias)

**Выигрыш**: ~15% быстрее нормализация, стабильнее обучение.

### 3. Pre-Norm архитектура

**Что**: нормализация ПЕРЕД attention/FFN, а не после.
```
Сейчас: x → Attention → Norm → FFN → Norm
LLaMA:  x → Norm → Attention → Norm → FFN
        + residual: x + Attention(Norm(x))
```

**Почему**:
- Стабильнее градиенты в глубоких сетях
- Позволяет увеличить число слоёв без проблем сходимости
- Стандарт для всех современных LLM (GPT-3, LLaMA, PaLM)

**Выигрыш**: стабильное обучение 3+ слоёв.

### 4. SwiGLU FFN

**Что**: gated FFN с SiLU-активацией.
**Формула**: `FFN(x) = (SiLU(x·W_gate) ⊙ (x·W_up)) · W_down`

**Почему**:
- У нас уже есть SiLU в FFN, но без gating — это недоиспользование
- SwiGLU даёт +5-10% качество при тех же параметрах (PaLM paper)
- Gating позволяет модели учить WHEN to apply which transformation

**Выигрыш**: +качество генерации без увеличения параметров.

### 5. Смешанная точность fp16

**Что**: вычисления в float16, веса в float32.
**PyTorch**: `torch.cuda.amp.autocast()` + `GradScaler`

**Почему**:
- Удвоение скорости обучения (Tensor Cores на GPU)
- Половина использования VRAM — больше batch size
- Стандарт для всех современных LLM

**Выигрыш**: ×2 скорость обучения, ×2 batch size.

## Что НЕ берём (и почему)

### Flash Attention — ❌
Сложная CUDA-зависимость (Triton), наше внимание (24-dim × 12 голов) и так быстрое. Преждевременная оптимизация.

### KV Cache — отложенно
Нужен для инференса, не для обучения. Добавим когда генерация станет стабильной.

### Multi-Query Attention — ❌
Экономия KV-голов неактуальна при 24-dim. Наша FractalAttention уже группирует головы по уровням.

### MoE (Mixture of Experts) — ❌
Для 150K параметров — абсурд. Актуально при >1B.

### Tokenizer BPE/SentencePiece — ❌
Принципиально: мы на character-level. Символ ≡ точка в ℝ²⁴. Токенизация разрушит эту связь.

## Сводка: что меняется в архитектуре

| Компонент | Было | Стало | Эффект |
|-----------|------|-------|--------|
| Position encoding | `pos_embed` (6K params) | **RoPE** (0 params) | -6K, +качество |
| Normalization | `LayerNorm` | **RMSNorm** | +15% скорость |
| Norm placement | Post-norm | **Pre-norm** | Стабильность 3+ слоёв |
| FFN | `SiLU → Linear` | **SwiGLU gate** | +5-10% качество |
| Точность | fp32 | **fp16 + GradScaler** | ×2 скорость |
| Слои | 1 | **3** | Иерархия символ→слово→предложение |
| Головы | 12 (4×3) | **16 (4×4)** | +масштаб 8 (кросс-словный) |
| d_model | 24 | **64** | d_k = 4 на голову |
| Параметры | 26 644 | **~140 000** | — |
| Прогноз acc | 33% | **65–75%** | — |

## Что ОСТАЁТСЯ уникальным для EVA

| Компонент | Почему не трогаем |
|-----------|-------------------|
| **CoordinateEmbedding** | Символ ≡ точка в ℝ²⁴ — фундамент всей системы |
| **CoordinateDecoder** | ℝ²⁴ → символ без параметров (nearest neighbor) |
| **FractalAttention** | 4 уровня × 4 масштаба + manifold bias — наше ядро |
| **PotentialDynamics** | STDP/LTP/LTD — живая пластика, аналога в LLM нет |
| **TrajectoryStore** | Память отдельно от модели — нет аналогов |
| **Character-level** | 157 токенов — не BPE, не слова, только символы |
| **Affinity → MDS → ℝ²⁴** | Координаты из статистики языка, не случайные |

---

## Итог

Из LLM берём ТОЛЬКО инженерные улучшения (RoPE, RMSNorm, Pre-Norm, SwiGLU, fp16), НЕ трогаем научное ядро. Гибрид: инженерия LLM + наука EVA.
