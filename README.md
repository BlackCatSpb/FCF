# EVA Symbolic — Самообучающаяся символьная модель 

> **Не LLM.** Символ = позиция в пространстве. Трансформер = навигатор.
> 160 символов, 10 757 параметров, 5 MB. Открытый исследовательский проект.

---

## Что это?

Программа, которая **видит текст как траектории в многомерном пространстве**.

Обычная языковая модель: «привет» → токен 4521 → вектор 256 чисел.
EVA Symbolic: «привет» → 6 точек в ℝ¹², соединённых в траекторию.

Каждый символ (`п`, `р`, `и`, `в`, `е`, `т`) — это не индекс в таблице, а **позиция в едином координатном пространстве**. Трансформер учится навигировать между этими позициями. Генерация текста = движение по координатам.

## Как это работает?

### Пространство символов

```
Буква 'п' → точка  (0.12, 0.67, 0.34, ...) в ℝ¹²
Буква 'р' → точка  (0.11, 0.68, 0.35, ...) в ℝ¹²
Буква 'и' → точка  (0.10, 0.69, 0.36, ...) в ℝ¹²
```

Чем чаще буквы встречаются рядом — тем ближе их точки в пространстве.
«п» и «р» рядом (часто в начале слов). «ъ» и «ь» далеко (никогда не встречаются).

### Траектории вместо токенов

```
Слово "привет" → [P_п → P_р → P_и → P_в → P_е → P_т]
                    └─── траектория в ℝ¹² ───┘

Предложение → последовательность траекторий
Абзац → последовательность предложений
Домен → кластер траекторий
```

Всё — один и тот же тип объектов. Разница только в масштабе.

### Обучение

**Шаг 1 — Affinity:** Модель читает текст и считает какие буквы с какими рядом.
Чем чаще `п→р` — тем сильнее связь.

**Шаг 2 — Координаты:** Из матрицы связей 160×160 строится карта в ℝ¹².
Близкие буквы → близкие координаты. Далекие → далекие.

**Шаг 3 — Трансформер:** Учится предсказывать следующую координату.
На входе: `[P_п, P_р, P_и]`. На выходе: `P_в`.
Loss: насколько предсказанная точка близка к реальной.

### Генерация текста

```
Пользователь: "при..."
Трансформер видит: [P_п, P_р, P_и]
Предсказывает: P_в (ближайшая к координатам «в»)
Декодер: P_в → символ 'в'
Следующий шаг: [P_п, P_р, P_и, P_в] → P_е → 'е'
...
Результат: "привет"
```

Не «выбери токен из 50 000». А «переместись на вектор V, ближайший символ = ответ».

## Почему это важно?

| | Обычная LLM | EVA |
|---|---|---|
| **Символ** | Индекс в таблице | **Позиция в ℝ¹²** |
| **Параметры** | 7B–1T | **10 757** |
| **Память** | 16+ GB | **5 MB** |
| **Обучение** | Градиентный спуск | Affinity + gradient |
| **Генерация** | Softmax(logits) | **Навигация по координатам** |
| **Знания** | В весах (чёрный ящик) | **В координатах + траекториях** |
| **Новый текст** | Забывает старое | **Добавляет траектории** |
| **2+2=4** | Выучено статистически | **Единственный путь в ℝ¹²** |

### Почему 10 757 параметров?

Потому что модель не хранит «знания» в весах. Веса — только навигатор.
Знания — в координатах символов и траекториях текстов.
Координаты 160 символов × 12 измерений = 1920 чисел = 7.5 KB.
Траектории хранятся отдельно в TRIE-дереве.

### Почему ℝ¹²?

12 измерений = 4 уровня × 3 оси на уровень.
- Уровень символов: 3D (160 точек помещаются)
- Уровень слов: 3D (центроиды траекторий)
- Уровень предложений: 3D (центроиды слов)
- Уровень доменов: 3D (кластеры предложений)

Одни и те же 12 измерений. Разная интерпретация на разных масштабах.
**Фрактальная вложенность** — как матрёшка.

## Что модель знает после обучения?

- **Какие буквы с какими рядом** → affinity matrix
- **Где каждая буква в пространстве** → координаты в ℝ¹²
- **Как перейти от одной буквы к другой** → векторы трансформера
- **Какие траектории валидны** → LogicBridge
- **Какие невозможны** → ContradictionFilter
- **Где проходит граница домена** → KnowledgeBase
