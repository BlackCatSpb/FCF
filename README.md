# FCF — Fractal Cognitive Field

**FCF** (Fractal Cognitive Field) — языковая модель без градиентного спуска, где смысл возникает как самоорганизация векторного поля в октантной (3D-фрактальной) системе координат.

Каждый концепт — точка в трёхмерном фрактале, заданная неповторяющимися десятичными цифрами (0–7 на уровень). Значение 0.235 → 3 цифры → x/y/z. Количество цифр = количество нулей (уровней вложенности). Координаты 0..7 на каждом уровне.

---

## Ключевые отличия от трансформеров

| Трансформеры (GPT, Llama) | FCF |
|---|---|
| Градиентный спуск (backprop) | Вычислительная вариативность = вариативность поля |
| Миллиарды параметров | 146K концептов × 384D |
| Неинтерпретируем | Каждый вектор концепта читаем и визуализируем |
| Аттеншен фиксирован | Маска = бинарная активация поля (shift + experience) |
| Токены — числа | Токены — точки в 3D-фрактале с октантными путями |
| Морфология — внешняя | Морфология встроена в координаты (LCP ≥ 12 для однокоренных) |

## Как это работает

### 1. Фрактальное кодирование (Octree H)

Любое число без повторяющихся цифр задаёт точку в трёхмерном фрактале:

```
0.235 → цифры: 2, 3, 5
         → x=0.2, y=0.3, z=0.5 (level 0)
         → x=0.02, y=0.03, z=0.05 (level 1 в подкубе 2,3,5)
```

- **path(число)** — последовательность октантов (0..7) для каждого уровня
- **LCP(a, b)** — длина общего префикса октантных путей (Longest Common Prefix)
- **H(i,j) = γ^LCP(i,j)** — иерархическая матрица 1024×1024, ~23% ненулевых

Два концепта, делящие октантный префикс длины L, активируют общие нейроны поля. Чем длиннее префикс — тем ближе концепты в поле.

### 2. Морфологическая токенизация (146K BPE + Natasha)

- **SentencePiece 146K** (вместо 32K) — как у QWEN. Средняя длина строки 33.5 токенов.
- **MorphVocab** — весь корпус (145K строк) пропущен через Natasha:
  - 337K уникальных слов → 86K сопоставлены токенам SP
  - 625 граммемных наборов
  - Каждому слову — **кастомный октантный путь**: `path(lemma_rank)[:12] + path(form_rank)[:4]`
  - LCP(князь, князьями) = 12 — однокоренные делят префикс октантного пути
- Остальные ~60K SP токенов (субсловные единицы, редкие слова) — стандартный путь

### 3. ConceptSpace — фрактальное поле

- 146K концептов, каждый — точка на сфере в 384D
- Код фрактала: z_c(256) + z_a(128) + z_m(128) = 512D
- Проекция: v = code @ basis (384D)
- Обучение: STDP (Spike-Timing-Dependent Plasticity):
  - Токен A раньше B → вектор B сдвигается в сторону A
  - Только вперёд, чтобы избежать коллапса
  - PMI-gate (шаблонные пары — малый вес)
  - Тета-ритм (позиция в предложении модулирует LR)
  - Frequency weighting (частые слова — низкий вес)
- **Lateral inhibition**: до 100 случайных концептов с cos > threshold
  - Riemannian gradient: отталкивание по геодезической сферы
  - O(1) indexed access через `_vec_array`
- **Fluctuation**: ланжевеновский дрейф в нуль-пространство
- **Field gate**: активация через octree overlap (не отдельный attention)

### 4. CrystalGenerator — генерация

- Beam search (width=3–5) по концептам
- PMI-gated графовый обход
- Анти-репетиция (штраф за повтор)
- Центроид запроса (query_words → cредний вектор)
- Гормональная модуляция (HormonalSystem)

### 5. DAG-иерархия через H

Каждое noun-anchor может быть complement другого anchor:
- H(i,j) = γ^LCP(i,j) задаёт силу связи
- LCP ≥ 6 → сильная связь (одно поле)
- Два слова с LCP ≥ 12 в морф. пути — формы одной леммы

## Производительность (FAST mode)

| Метрика | Значение |
|---|---|
| Vocab | 146K |
| Скорость | 32 L/s (было 3 L/s без оптимизаций) |
| Память | 2.8 GB (было 5.1 GB) |
| ETA (полный корпус) | ~1h13m (было ~13h) |
| Checkpoint | 276 MB (4.8 MB JSON + 271 MB npz) |

Оптимизации:
- PMI gate: `_prefix_total` + `_skip2_total` кеши (9.7×)
- `_vec_array` + `get_vec/set_vec` O(1) доступ
- Lateral inhibition: `randint+unique` вместо `permutation` (30×)
- В FAST mode: n-граммы не загружаются (pmi_gate=False)

## Мотивация

FCF — это не попытка повторить GPT с меньшими ресурсами. Это эксперимент: *можно ли построить семантическое пространство без градиентного спуска, используя только локальные правила пластичности и фрактальную систему координат?*

Если ответ «да» — открывается путь к полностью интерпретируемым языковым моделям, где каждое решение объяснимо через геометрию фрактального поля.
