# EVA — Топологический ИИ нового поколения

> **Не LLM. Не статистический попугай.**  
> Символ ≡ точка в ℝ²⁴. Текст ≡ траектория. Трансформер ≡ навигатор.  
> Знания — в геометрии пространства, не в весах.

---

## Идея за 30 секунд

Обычный ИИ: «привет» → токен #4521 → вектор из 768 чисел → угадать следующий токен.

**EVA**: «привет» → 6 точек в ℝ²⁴, соединённых в траекторию → найти путь → исполнить инструкцию.

Модель не «предсказывает следующее слово». Она **навигирует в координатном пространстве**, где каждый символ — точка, каждое слово — путь, а знание — топология всех возможных путей.

## Архитектура

```
         ┌──────────────┐
ТЕКСТ →  │  Affinity    │  Статистика co‑occurrence 157×157
         │  (PotentialField) │
         └──────┬───────┘
                ↓ MDS
         ┌──────────────┐
         │  ℝ²⁴ Координаты │  Каждый символ — точка в 24‑мерном пространстве
         │  (TopologicalField) │
         └──────┬───────┘
                ↓
         ┌──────────────┐
         │  FractalAttention │  12 голов = 4 уровня × 3 масштаба
         │  UnifiedTransformer │  26,644 параметра
         └──────┬───────┘
                ↓
         ┌──────────────┐
ТЕКСТ ←  │  CoordinateDecoder │  ℝ²⁴ → ближайший символ
         └──────────────┘
```

| Компонент | Назначение | Параметры |
|-----------|-----------|-----------|
| **PotentialField** | Affinity matrix: статистика co‑occurrence | 157×157 |
| **TopologicalField** | MDS: affinity → координаты в ℝ²⁴ | 0 |
| **FractalAttention** | 4 уровня × 3 масштаба = 12 голов | в составе UT |
| **UnifiedTransformer** | Координатный навигатор | **26,644** |
| **CoordinateDecoder** | ℝ²⁴ → символ (nearest‑neighbor) | 0 |
| **PotentialFunction V(z)** | Скалярный потенциал над ℝ²⁴ | 28,545 |
| **PotentialDynamics** | STDP/LTP/LTD живая пластика | 0 |
| **TrajectoryStore** | Хранилище всех траекторий | ∞ |

## Ключевые отличия от LLM

| | LLM (GPT, Claude, LLaMA) | EVA |
|---|---|---|
| **Принцип** | Статистическое угадывание | Навигация в координатном пространстве |
| **Символ** | Индекс в таблице эмбеддингов | Точка в ℝ²⁴ |
| **Знания** | В миллиардах весов (неотделимы) | В топологии траекторий (отдельно от модели) |
| **Параметры** | 1.7B – 1.7T | **26,644** (в 64,000× меньше) |
| **Память** | 16GB – 1TB+ VRAM | **5 MB** модель + траектории |
| **Интерпретация** | Black box | Каждое решение — путь в ℝ²⁴ |
| **Обучение** | Статичное, $100M+ | Непрерывное: STDP, LTP/LTD, метапластичность |
| **Новое знание** | Только дообучение (catastrophic forgetting) | Диалектический синтез через седловые точки |
| **Масштабирование** | Больше параметров | Больше траекторий (модель не растёт) |
| **Мультимодальность** | Отдельные энкодеры для каждой модальности | Всё → ℝ²⁴ (единое пространство) |
| **2+2=4** | Выучено статистически | Единственный путь в ℝ²⁴ (геометрическая гарантия) |

## Научные инновации

### 1. Символ как координата
Символ — не индекс в таблице, а **вычисленная позиция** в ℝ²⁴. Позиция определяется не случайной инициализацией, а **статистикой языка**: MDS из affinity matrix. Символы, часто встречающиеся рядом, получают близкие координаты.

### 2. Текст как траектория
«Привет мир» — не последовательность из двух токенов. Это **траектория из 10 точек** в ℝ²⁴. Порядок координат = инструкция для трансформера.

### 3. Знания ≠ веса
Веса модели — только **навигатор** (как перейти от точки А к точке Б). Сами знания — в **топологии пространства**: координаты символов, траектории текстов, affinity матрица. Модель можно заменить — знания останутся.

### 4. Живая пластика (PotentialDynamics)
Affinity матрица не статична. STDP (Spike‑Timing‑Dependent Plasticity) усиливает часто используемые связи и ослабляет неиспользуемые. LTP/LTD — долговременная потенциация/депрессия. Гомеостаз предотвращает runaway. **Модель улучшается от использования.**

### 5. Фрактальная размерность
24 измерения используются как **4 уровня × 6 осей**: символ → слово → предложение → текст. FractalAttention с 12 головами работает на всех масштабах одновременно. Матрёшка: одни и те же оси, разная интерпретация.

### 6. Диалектический синтез
Новые концепты не интерполируются между известными. Они возникают через **гегелевскую диалектику**: тезис ⊕ антитезис → синтез. Седловая точка в потенциале V(z) между двумя концептами — кандидат на новый концепт. Градиентный спуск из седла находит новую котловину.

### 7. Топологическая память (TrajectoryStore)
Все траектории декодирования сохраняются. При генерации извлекаются похожие траектории как контекст (RAG). Память отделена от модели — можно добавить миллиард траекторий без изменения навигатора.

### 8. Иммунная система (ContradictionFilter)
5 типов противоречий: структурные, порядковые, семантические, контекстные, частотные. Фильтр **запоминает что НЕЛЬЗЯ**, а не вычисляет что можно. Эффективнее на порядки.

```bash
git clone https://github.com/BlackCatSpb/FCF.git
cd FCF
pip install torch numpy scikit-learn loguru

# Символы (2 минуты)
```
