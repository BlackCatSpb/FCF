# EVA Symbolic — Самообучающаяся символьная модель

> **Не LLM.** 160 символов, 1.3M параметров, 5 MB на диске.
> Учится как ребёнок: от букв — к словам, от слов — к предложениям.
> Count-based обучение без градиентов. Открытый исследовательский проект.

---

## Что это?

Программа, которая учится читать по-русски с нуля. Она не знает ни одного слова. Только 160 символов (буквы, цифры, знаки). Читая текст, она запоминает какие буквы часто идут друг за другом.

После обучения модель знает:
- Как буквы складываются в слова (п → р → и → в → е → т)
- Какие сочетания невозможны (ъь, щы — такого не бывает)
- Как закончить начатое слово (мам... → а, е, ы)
- В каком порядке буквы в известных словах (привет, человек, природа)

## Как это работает?

**Никакого градиентного спуска.** Только счётчик co-occurrence:

```
Если 'п' и 'р' встретились рядом 100 раз → сила связи = 1.0
Если 'ъ' и 'ь' никогда не встречались   → сила связи = 0.5
```

Вся память модели — таблица 160×160 (25 600 чисел, 96 КБ).

## Почему это интересно?

| | Обычная LLM (GPT) | EVA Symbolic |
|---|---|---|
| Размер | 7B–1T параметров | **1.3M параметров** |
| Память | 16+ GB | **5 MB** |
| Обучение | Градиентный спуск | **Счётчик (без градиентов)** |
| Дообучение | Требует дата-центр | **На лету, на ноутбуке** |
| Объяснимость | Чёрный ящик | **Каждое решение = конкретный счётчик** |
| Запуск | GPU 16+ GB | **CPU или 2 GB GPU** |

## Текущий статус

- ✅ Символьный слой обучен (112K батчей, 7.4K диграмм)
- ✅ Count-based affinity с дифференциацией (std=0.12)
- ✅ 30+ модулей: топология, противоречия, концепты, сон, мышление
- 🔄 Обучение трансформера (knowledge distillation от affinity)
- 🔄 DataSphere-ноутбук для масштабирования
