# EVA Symbolic — Самообучающаяся символьная модель

> Не предсказание токенов. Накопление потенциалов связей между символами.
> Веса — алфавит. Знания — матрица 160×160 (96 KB). Модель учится как ребенок: от букв к словам.

## 1. Философия

### 1.1 Отличие от LLM

| Классическая LLM | EVA Symbolic |
|------------------|--------------|
| Веса = знания (всё в матрицах) | Веса = движок внимания. Знания = **матрица 160×160 (96 KB)** |
| Обучение = backprop + кросс-энтропия | Обучение = **счётчик co-occurrence** (без градиентов) |
| Токенизатор = BPE (50K слов) | Токенизатор = **символьный (156 символов)** |
| 7B–1T параметров, 16+ GB VRAM | **1.3M параметров, 2 GB VRAM или CPU** |
| Дообучение = дата-центр | Дообучение = **на лету, на пользовательском ПК** |
| Объяснимость = чёрный ящик | **Каждое предсказание → конкретный счётчик** |
| Catastrophic forgetting | **Счётчики только растут** |

### 1.2 Единственная формула обучения

```
affinity[i][j] = 0.5 + 0.5 × min(count[i][j] / 100, 1.0)
```

- 0 встреч → 0.500 (нейтрально)
- 50 встреч → 0.750 (умеренная связь)
- 100+ встреч → 1.000 (сильная связь)

**Никакого градиентного спуска. Никакого backpropagation.** Просто счётчик.

### 1.3 Принцип: отсечение невозможного вместо перебора возможного

```
ВСЕ_СВЯЗИ - ПРОТИВОРЕЧИЯ - ИЗВЕСТНОЕ = ПРОСТРАНСТВО_КОНЦЕПТОВ
```

Модель НЕ перебирает 160^N комбинаций. Она:
1. **Отсекает невозможное** (ContradictionFilter)
2. **Усиливает частое** (счётчик co-occurrence)
3. **Ищет новое** в оставшемся пространстве (ConceptMiner)

## 2. Архитектура (25 модулей)

```
Текст → CharacterVocab → [с][и][м][в][о][л][ы] (156 токенов)
  ↓
Transformer (1.3M) → attention_matrix
  ↓
┌─────────────────────────────────────────────────────┐
│ ОБУЧЕНИЕ (count-based)                               │
│   Для каждой строки:                                 │
│   → символы → соседние пары → инкремент счётчика     │
│   → affinity = 0.5 + 0.5 × min(count/100, 1)        │
└─────────────────────────────────────────────────────┘
  ↓
Периодически:
  🔍 AssemblyGrammar.discover_digrams (пары > avg+0.02)
  🗺️ TopologicalField (MDS: аффинность → координаты)
  🏘️ NaturalClusterer (домены из плотности)
  🔭 ConceptMiner (поиск в свободном пространстве)
```

## 3. Логика ключевых методов

### 3.1 PotentialField — матрица аффинности

**Формула (count-based):**
```
strengthen(i, j):
    co_occurrence_count[i][j] += 1
    affinity[i][j] = 0.5 + 0.5 × min(count[i][j] / 100.0, 1.0)
```

**Почему count-based, а не EMA:**
- EMA-формула `affinity = (1-lr)*affinity + lr` насыщается при большом числе итераций (все значения → 1.0)
- Count-based имеет жёсткую верхнюю границу (1.0) и не насыщается
- 10 миллиардов обновлений за 800K шагов — с EMA это приводит к 0.9998 для всех частых пар
- Count-based даёт **std=0.13** (дифференциация), EMA давал **std≈0** (все одинаковы)

### 3.2 SymbolicGenerator — генерация

**Алгоритм (на каждом шаге):**
1. **База (80%):** MultiLevelPredictor — контекст из N символов
2. **Шум (20%):** логиты трансформера (temperature=2.0)
3. **Фильтр:** обнулить запрещённые символы (ContradictionFilter)
4. **Буст:** усилить известные диграммы (×1.5)
5. **Семпл:** temperature + top-k + top-p

### 3.3 ContradictionFilter — что НЕЛЬЗЯ

Запреты трёх типов:
- **Структурные:** циклы A→B→A без прогрессии, разрывы (affinity < 0.05)
- **Семантические:** cos(continuation_A, continuation_B) < -0.3
- **Частотные:** пара ни разу не встретилась + противоречит структурным паттернам

### 3.4 AssemblyGrammar — иерархия паттернов

**Уровень 0 (диграммы):** пары символов с affinity > avg + 0.02
**Уровень 1 (N-граммы):** цепочки через общие символы (BFS по графу)
**Уровень 2 (слова):** композиция N-грамм
**Уровень 3 (фразы):** композиция слов
