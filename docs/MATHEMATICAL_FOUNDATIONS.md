# Математические основы FCF — λ_d-иерархия

### Определение 1: λ_d — обобщённое золотое сечение порядка d

λ_d — единственный положительный действительный корень характеристического уравнения рекурренции порядка d:

$$x^d = x^{d-1} + x^{d-2} + \dots + x + 1$$

Эквивалентная форма, удобная для вычисления:

$$\lambda_d = 2 - \lambda_d^{-d}$$

Из этого непосредственно следует фундаментальное тождество:

$$\lambda_d - 1 = \lambda_d^{-d}$$

Для d=2 это даёт классическое φ: φ - 1 = φ^{-1} = 0.618…

Для d→∞: λ_d → 2, λ_d - 1 → 1.

---

### Определение 2: F^(d)_n — обобщённый ряд Фибоначчи порядка d

$$F^{(d)}_n = \sum_{k=1}^{d} F^{(d)}_{n-k}$$

с начальными условиями:

$$F^{(d)}_0 = 1, \quad F^{(d)}_{-k} = 0\;(1 \leq k < d)$$

Асимптотика для больших n:

$$F^{(d)}_n \sim \frac{\lambda_d^{\,n-1}}{\sum_{k=1}^{d} k \cdot \lambda_d^{\,k-1}}$$

---

### Теорема 1: λ_d-иерархия коэффициентов

Всякий коэффициент K архитектуры FCF принадлежит одному из следующих классов:

**Класс A — глубина k:** нисходящий ряд

$$\boxed{K = \lambda_d^{-k}} \qquad k \in \mathbb{Z}$$

| k | Применение |
|---|------------|
| 2 | RRF-graph weight, subspace `z_c` |
| 1 | DA baseline, PMI slope, anti-rep decay |
| 0 | Subspace `z_a`, identity |
| −1 | Subspace `z_m`, RRF-vector |
| −2 | RRF-prior |
| −4 | 5HT baseline, ACh match strength |
| −6 | Tonic decay complement |

**Класс B — ёмкость n:** целые числа Фибоначчи

$$\boxed{K = F^{(d)}_n} \qquad n \in \mathbb{N}$$

| n | Значение (d=2) | Применение |
|---|----------------|------------|
| 3 | 2 | target_boost_temp, hormonal_mod, mastery, центр кластера |
| 4 | 3 | field_weight_cap, boredom_repeat |
| 5 | 5 | target_boost, boredom_window, na_baseline, well_known_floor |
| 8 | 21 | da_coherence, da_temperature_min |
| 10 | 55 | hormone_recent_window |
| 16 | 987 | reward_history_maxlen, rrf_prior_freq_cap |

**Класс C — moderation:** единый инвариант

$$\boxed{K = \frac{\lambda_d - 1}{2} = \frac{1}{2\lambda_d^{\,d}}}$$

Появляется в 10+ подсистемах: homeostatic_boost, homeostatic_rrf, intent_bonus, neg_lr, na_confidence, na_adapt, ach_novelty_baseline, ht_baseline_part, rrf_boost_homeostasis, da_mismatch_penalty (отрицательный).

**Класс D — decay:** дополнение до единицы

$$\boxed{K = 1 - \lambda_d^{-m}} \qquad m \in \mathbb{N}$$

| m | Применение |
|---|------------|
| 4 | phasic_decay |
| 6 | tonic_decay |

**Класс E — информационный:** логарифмический масштаб

$$\boxed{K = \frac{1}{\log(\lambda_d \cdot V)}}$$

где V — размер словаря.

### Теорема 2: RRF-веса как σ-алгебра глубин

RRF-веса образуют нормированную сумму λ_d^k по глубинам k ∈ {−2, −1, 0, 1, 2}:

$$
w_k = \frac{\lambda_d^{\,k}}{\sum_{j=-2}^{2} \lambda_d^{\,j}}
$$

$$\sum_{k} w_k = 1$$

---

### Теорема 3: Балансировка подпространств

Размерности подпространств латентного кода следуют λ_d² : λ_d : 1:

$$l_c : l_a : l_m = \lambda_d^2 : \lambda_d : 1$$

Отсюда:

$$l_c = L \cdot \frac{\lambda_d^2}{\lambda_d^2 + \lambda_d + 1}, \quad
l_a = L \cdot \frac{\lambda_d}{\lambda_d^2 + \lambda_d + 1}, \quad
l_m = L \cdot \frac{1}{\lambda_d^2 + \lambda_d + 1}$$

Для d=2: 0.618 : 0.236 : 0.146 (точные доли).

### Теорема 4: Гормональные базлайны — глубины k = 1..4

Каждый нейромодулятор соответствует глубине k (быстрота реакции):

| Модулятор | k | Базлайн | Функция |
|-----------|---|---------|---------|
| DA | 1 | λ_d^{-1} | per-token, немедленное подкрепление |
| ACh | 2 | λ_d^{-2} | n-gram, неопределённость/сюрприз |
| NA | 3 | λ_d^{-3} | phrase, уверенность/адаптация |
| 5HT | 4 | λ_d^{-4} | sentence, долговременное планирование |

Межгормональные связи:

$$DA_{phasic \to tonic} = \lambda_d^{-3}, \quad
ACh_{phasic\;integration} = \lambda_d^{-2}, \quad
NA_{beam} = \lambda_d^{-1}$$

### Теорема 5: Принцип лакун (Gap Principle)

Пусть e — эмпирический коэффициент, не имеющий λ_d-вывода вида A–E ни для какого целого k, n, d.

Тогда e указывает на **пропущенный архитектурный элемент** на позиции (k, n, d) в иерархии.

**Процедура закрытия лакуны:**
1. Определить (k, n, d) по значению e
2. Построить механизм на этой глубине
3. Вычислить новый коэффициент из λ_d; проверить, что e ≈ λ_d^{-k} (или другая форма)
4. Удалить эмпирическую константу

В FCF все лакуны закрыты. 0 эмпирических констант.

### Единая производящая функция

Вся иерархия порождается одной рекурренцией:

$$\boxed{\lambda_d^d = \lambda_d^{d-1} + \lambda_d^{d-2} + \dots + \lambda_d + 1}$$

Из неё следуют:
- Все коэффициенты (как отрицательные степени)
- Все ёмкости (как числа ряда)
- Все соотношения (как отношения последовательных членов)
- Все ограничения (как дополнения до 1)

FCF — не модель с гиперпараметрами.  
FCF — развёртывание λ_d в архитектуру.
