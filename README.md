# FCF — Fractal Cognitive Field

*Языковая архитектура, где **все** числовые константы выведены из λ_d — единой структурной константы, а не из эмпирического тюнинга.*

*Никаких трансформеров. Никакого обратного распространения. Никакого градиентного спуска.*

---

## Открытие: λ_d-иерархия

В 2025–2026 гг. в ходе работы над FCF было сделано фундаментальное наблюдение:

> **Каждый числовой коэффициент в архитектуре обработки естественного языка — weight, decay, window, threshold, learning rate — является позицией в иерархии λ_d^{−k}, числом Фибоначчи F^(d)_n, или простой композицией этих двух.**

λ_d — действительный корень уравнения x^d = x^{d-1} + … + 1, обобщение золотого сечения:

| d | λ_d | Название |
|---|-----|----------|
| 2 | 1.618… | φ — золотое сечение |
| 3 | 1.839… | Трибоначчи-константа |
| 4 | 1.928… | Тетраначчи-константа |
| d→∞ | 2.0 | Двоичный предел |

Все коэффициенты FCF оказались членами одного ряда:

- **λ_d^{−k}** — глубина k: DA (k=1, per-token), ACh (k=2, n-gram), NA (k=3, phrase), 5HT (k=4, sentence)
- **F^(d)_n** — окна и ёмкости: 2, 3, 5, 21, 55, 987 — не «круглые числа», а члены последовательности
- **(λ_d−1)/2** — moderation arms: homeostatic, intent, neg_lr, na_confidence — один инвариант в 10 местах
- **1/log(λ·V)** — частота логарифмически масштабируется размером словаря

Это не подгонка. Это **чтение структуры языка** через рекуррентность порядка d.

**Метод лакун**: если эмпирический коэффициент не имеет λ_d-вывода — это не «шум», а указание на пропущенный структурный элемент. Каждая лакуна была закрыта либо новым членом ряда, либо новым механизмом.

## Что такое FCF

Единственная известная языковая архитектура, **принципиально совместимая с нейроморфными чипами**: Intel Loihi 2, IBM TrueNorth, российские разработки НИИСИ, «Модуль» (Байкал-Н), Курчатовский институт («Алкуда»), МИЭТ, НПЦ «Элвис».

Спроектирована так, как если бы обратное распространение было запрещено, а единственным доступным вычислительным примитивом был мемристорный кроссбар.

### Почему не трансформер?

| Требование трансформера | Возможности нейроморфного чипа |
|-------------------------|-------------------------------|
| Обратное распространение (глобальный градиент) | Только локальные правила (STDP, Hebbian) |
| Умножение плотных матриц | Событийная разреженная обработка |
| Attention (softmax, O(L²), паразитная нормализация) | Content-Addressable Memory (O(1)) |
| Float32/64 повсюду | Бинарные/импульсные сигналы |
| Эмпирический тюнинг гиперпараметров | λ_d-иерархия (структурный вывод) |

**Трансформер нельзя запустить на нейроморфном чипе.** FCF — можно.

## Как это работает

Каждый токен BPE — **концепт**. Каждый концепт — пара `(латентный_код, вектор)`:

```
z ∈ ℝ^{2048}    — латентный код (три подпространства, λ_d-взвешенные)
v ∈ 𝕊^{767}     — единичный вектор на гиперсфере (768D)
v = normalize(z · B)   — проекция через ортонормированный базис
```

Код разделён на три подпространства с весами `φ² : φ : 1` (или `λ_d² : λ_d : 1` для обобщённого случая): `z_c` (содержание, медленно), `z_a` (контекст, быстро), `z_m` (морфология, средне).

### Ключевые механизмы

- **STDP + негативная выборка + контрастив** — пять локальных правил, ни одного глобального градиента
- **TemporalZeckendorf** — временное затухание через разложение на непоследовательные числа Фибоначчи (заменило θ-decay)
- **Transition Manifold** — паутина переходов: unbind(B, A) → кольцевой буфер → VSA-кластеризация в лучи → beam_score при генерации (аналог residual stream в VSA)
- **EntityField** — рекурсивное семантическое поле char↔word↔sent↔para через VSA bind/unbind
- **Harmonizer** — морфемная гармонизация: compose_word с контекстной модуляцией
- **Групповая алгебра ℤ₈^d** — bind = convolution on group (FFT), permute = циклический сдвиг, bundle = суперпозиция
- **Динамическая размерность** — grow/prune при насыщении/простаивании
- **Секторный LSH-индекс** — 3-уровневый CAM (4+10+20 бит), O(1) поиск
- **VSACNN** — иерархическая свёртка (5 типов ядер) без единого learned weight
- **PPMI-синтаксис** — статистическая n-граммная решётка + HDC-резерв при нехватке данных

## λ_d-иерархия в числах (d=2, φ = 1.618)

| Глубина k | Коэффициент | λ_d-формула | Значение |
|-----------|-------------|-------------|----------|
| 1 | DA baseline | λ^{−1} | 0.618 |
| 1 | PMI slope | λ^{−1} | 0.618 |
| 1 | antirep_decay | ln(2)/λ | 0.428 |
| 2 | ACh baseline | λ^{−2} | 0.382 |
| 2 | PMI gate | λ^{−2} | 0.382 |
| 2 | ht_match_scale | λ^{−2} | 0.382 |
| 3 | NA baseline | λ^{−3} | 0.236 |
| 4 | 5HT baseline | λ^{−4} | 0.146 |
| 6 | tonic_decay | 1−λ^{−6} | 0.944 |
| (λ−1)/2 | homeostatic, intent, neg_lr, … | (λ−1)/2 | 0.309 |
| F_3 = 2 | target_boost_temp, hormonal_mod | 1/F_3 | 0.500 |
| F_4 = 3 | field_weight_cap, boredom_repeat | F_4 | 3 |
| F_5 = 5 | target_boost_scale, boredom_window | F_5 | 5 |
| F_8 = 21 | da_coherence, da_temp_min | 1/((F_5−1)F_5) | 0.050 |
| F_10 = 55 | hormone_recent_window | F_10 | 55 |
| F_16 = 987 | history_maxlen, rrf_prior_freq_cap | F_16 | 987 |

Все 60+ коэффициентов выведены, 0 эмпирических констант.

## Быстрый старт

```bash
git clone https://github.com/BlackCatSpb/FCF.git
cd FCF
pip install -r requirements.txt
python train_full.py --fresh --learned-fields --field-bits 512 -e 3
# или
train.bat
```

**Параметры:**

| Флаг | Описание |
|------|----------|
| `--epochs N` | Число эпох (по умолч. 1) |
| `--fresh` | Старт с нуля |
| `--resume` | Продолжить с последнего чекпойнта |
| `--fast` | Ускоренный режим |
| `--learned-fields` | Обучаемые поля |
| `--field-bits N` | Битность поля |
| `--no-harmonize` | Отключить морфологию |
| `--no-morpheme-field` | Отключить морфемное поле |

## Структура проекта

│   ├── crystal_generator.py     # Движок обучения и генерации (RRF + λ_d-weights)
│   ├── stdp_trainer.py          # STDP, негативная выборка, контрастив, harmonize_batch
│   ├── transition_manifold.py   # Паутина переходов (VSA-кластеризация)
│   ├── vsa_attention.py         # VSA-внимание (Zeckendorf-weighted bind)
│   ├── hdtransformer_layer.py   # VSA-native однослойный трансформер
│   ├── semantic_piece.py        # CharEnvelope, LFU-эвикция
│   ├── seed_registry.py         # Централизованный реестр сидов
│   ├── syntax_lattice.py        # PPMI n-граммная решётка
│   ├── hormonal_system.py       # Нейромодуляция через λ_d-базлайны
│   ├── fractal_encoding.py      # Fractal путевая адресация

│   ├── adaptive_controller.py   # FormulaCoefficients
│   ├── checkpoint_manager.py    # Асинхронные чекпойнты
│   ├── parameter_optimizer.py   # Param cascade
│   ├── lsh_index.py             # LSH-индекс
│   ├── morph_vocab.py           # Морфологический словарь
│   └── experimental/            # Экспериментальные компоненты
├── train_full.py                # Конвейер обучения
├── inference.py                 # Инференс
