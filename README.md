# FCF — Fractal Cognitive Field

**FCF** (Fractal Cognitive Field) — нейро-символическая языковая модель без градиентного спуска. Смысл возникает как самоорганизация векторного поля в октантной (3D-фрактальной) системе координат.

Каждый концепт — точка на единичной сфере в 384D. Координаты задаются через фрактальный код (неповторяющиеся цифры 0–7 на уровень) и проекцию через ортонормированный базис.

---

## Ключевые отличия от трансформеров

| Трансформеры (GPT, Llama) | FCF |
|---|---|
| Градиентный спуск (backprop) | STDP + lateral inhibition + centroid pull |
| Миллиарды параметров | 146K концептов × 384D |
| Неинтерпретируем | Каждый вектор концепта читаем |
| Аттеншен фиксирован | Маска = бинарная активация поля |
| Токены — числа | Токены — точки в 3D-фрактале |
| Морфология — внешняя | Морфология встроена в октантный путь (LCP ≥ 12 для однокоренных) |

---

## Компоненты

- **SentencePiece 146K BPE** — токенизатор (аналогично QWEN)
- **MorphVocab** — морфологическая разметка через Natasha (86K path_overrides, LCP=12 для однокоренных)
- **ConceptSpace** — 146K × 384D векторы на сфере, code(512) @ basis(512×384)
- **SyntaxLattice** — n-граммы (2/3/4), Octree H(1024×1024), PMI кеш
- **FractalField** — field_bits (octree overlap), meta_gate
- **CrystalGenerator** — beam search по концептам, PMI-gated графовый обход, гормональная модуляция

## Обучение

### Механизмы пластичности

| Механизм | Описание |
|---|---|
| **STDP** | Токен A раньше B → вектор B сдвигается в сторону A. Batched GPU matmul |
| **Continuous PMI gate** | pmi_strength (0..1) адаптируется через ParameterOptimizer по cos-тренду. Вместо жёсткого bool-флага |
| **Per-concept error threshold** | EMA ошибки на концепт. Высокая ошибка → ниже порог → больше пар для плохо предсказанных токенов |
| **Sentence centroid pull** | Все токены предложения → к общему центроиду (CBOW-like, LR × 0.1) |
| **Lateral inhibition** | Riemannian gradient — отталкивание по геодезической сферы. CPU sampling при G<50, GPU full-V при G≥50 |
| **Fluctuation** | Ланжевеновский дрейф в нуль-пространство с PPMI-шумом |

### GPU

- Micro-batching (BATCH_SIZE=32) — scatter_add эффективнее
- GPU matmul для sims (gv_t @ gv_all.T) и evaluate (2025 vs _vecs_t)
- CPU lateral inhibition при малом числе генераторов (G<50)

### Corpus

- Исходный: `full_corpus_ru.txt` (153K строк, 30M символов, ~52MB, UTF-8)
- Очищенный: `full_corpus_ru_clean.txt` (−61 строка мусора: URL-артефакты, ISBN, битые ссылки)
- Валидация: 5% хвоста корпуса, `eval_max_lines=300`

## Запуск

```bash
# Полное обучение (3 эпохи, свежий старт)
python train_full.py --epochs 3 --fresh

# Быстрый старт (1 эпоха, ускоренный режим)
python train_full.py --fast

# Продолжить с последнего чекпоинта
python train_full.py --epochs 3 --resume
```

## Мотивация

FCF — эксперимент: *можно ли построить семантическое пространство без градиентного спуска, используя только локальные правила пластичности и фрактальную систему координат?*

Если ответ «да» — открывается путь к полностью интерпретируемым языковым моделям, где каждое решение объяснимо через геометрию фрактального поля.
